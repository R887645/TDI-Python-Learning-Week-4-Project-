In this Week 4 project, I focused on cleaning and validating the supply chain dataset. This week was all about detecting missing values, duplicates, formatting inconsistencies, and logical errors — then applying fixes to make the dataset reliable for analysis.

This experience showed me how messy raw data can be, and why cleaning is the most important step before analysis. By standardizing strings, handling missing values, removing duplicates, and documenting every change, I transformed the dataset into a trustworthy foundation for deeper insights.

Key Skills Practiced
- Reading and writing files safely
- Cleaning and standardizing text with string methods
- Converting and validating data types
- Detecting and handling missing values
- Identifying and removing duplicates
- Spotting logical errors like negative quantities or impossible dates
- Documenting cleaning decisions clearly

What I Implemented
- Built a data quality report to assess issues
- Standardized supplier and product names
- Applied rules to handle missing values
- Removed true duplicates while keeping legitimate repeats
- Flagged and corrected logical errors in quantities, prices, and dates
